## Rules

- All copy in English, sentence case, written for a freelancer who is not an engineer. Explain "reserve" once as "money set aside for your tax prepayment".
- Every number has its unit (USDC or S/). Use tabular numerals.
- Every interactive element has visible hover, focus and disabled states. Keyboard reachable.
- Loading, empty and error states are different from each other and never show developer commands.
- No backend, no database, no API keys. The app reads the chain directly.
